# Tasbeeh Hasan | Portfolio

A hand-coded, single-page portfolio (HTML, CSS, JavaScript). No build step.

## Structure

```
index.html
css/style.css
js/data.js        all content (projects, achievements, certificates, experience)
js/script.js      rendering and interactivity
assets/Tasbeeh_Hasan_CV.pdf
README.md
```

Keep this folder structure. `index.html` loads `css/style.css`, `js/data.js`, and `js/script.js` by path, so the site breaks if the files are uploaded flat.

## View locally

Open `index.html` in a browser.

## Edit content

Change the text in `js/data.js`. The page re-renders automatically.
